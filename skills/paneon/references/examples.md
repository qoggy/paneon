# One-off explanatory examples

These two pages keep their title, topic, fixed data and initial values in source. Run them as they are, or copy the complete skill directory and edit the source to write a new explanation for the current conversation. They take no business JSON input and are not built-in pages.

`<skill>` is the absolute path of this skill directory. Run either page and give the human the returned URL:

```bash
paneon panel run <skill>/assets/examples/concurrency/panel.tsx --cwd /work/project --json
paneon panel run <skill>/assets/examples/sentinel-leap-array/panel.tsx --cwd /work/project --json
```

## Concurrency and queueing

Tasks A/B/C/D take 4/2/3/1 seconds and enter the queue in order at virtual t=0. Scheduling is FIFO and non-preemptive; at any instant all finished tasks are released before new tasks start in order. Serial and the selected concurrency share the same 0–10 second scale and show waiting, start, end and total batch time. Concurrency 1/2/3/4 gives total batch times of 10/5/4/4 seconds.

Changing concurrency in the input reschedules, pauses and returns to 0 seconds. Play, pause, step forward 1 second and replay change only page-local state. Fixed durations and no resource contention are model assumptions, not a prediction of real speedup.

The human can submit `explanation-feedback` through the shared selection and comment controls:

```ts
type SimulationRef =
  | { kind: 'task'; taskId: string; concurrency: number; atMs: number }
  | { kind: 'summary'; concurrency: number };
// payload: Feedback<SimulationRef>, containing only annotations and an optional overall comment.
```

A target records the concurrency and time at selection. Locating an old target replays that situation. Text targets refer to the original strings generated by the example. An empty comment means a plain selection; there is no separate selected list. Only an explicit click on 「提交评论」 emits an event; browsing and draft edits do not. The standard pages' `replacesEventId` policy is not enforced, and an ended agent is not woken automatically.

```bash
paneon panel events <instance-id> --consumer explanation-agent --wait-ms 0 --json
paneon panel ack <instance-id> --consumer explanation-agent --through <event-id> --json
```

Comment flow: select text normally and click the nearby 「评论」, or click 「选择对象」 in the compact toolbar to pick tasks or the batch total. 「保存」 only keeps a page draft; a numbered marker reopens it to cancel the edit, save or delete. 「提交评论」 sends the complete result; unsaved edits must first be saved or cancelled.

## Sentinel LeapArray

The authoritative source is fixed at [alibaba/Sentinel commit a3f40ba8e900c8489bd520274739f17235a7721c](https://github.com/alibaba/Sentinel/tree/a3f40ba8e900c8489bd520274739f17235a7721c). The page links these implementations at that version:

- [LeapArray](https://github.com/alibaba/Sentinel/blob/a3f40ba8e900c8489bd520274739f17235a7721c/sentinel-core/src/main/java/com/alibaba/csp/sentinel/slots/statistic/base/LeapArray.java): mapping, `currentWindow` branches, `values`, expiry check.
- [WindowWrap](https://github.com/alibaba/Sentinel/blob/a3f40ba8e900c8489bd520274739f17235a7721c/sentinel-core/src/main/java/com/alibaba/csp/sentinel/slots/statistic/base/WindowWrap.java): left-closed, right-open bucket interval.
- [BucketLeapArray](https://github.com/alibaba/Sentinel/blob/a3f40ba8e900c8489bd520274739f17235a7721c/sentinel-core/src/main/java/com/alibaba/csp/sentinel/slots/statistic/metric/BucketLeapArray.java): updates the start time and resets metrics.
- [MetricBucket](https://github.com/alibaba/Sentinel/blob/a3f40ba8e900c8489bd520274739f17235a7721c/sentinel-core/src/main/java/com/alibaba/csp/sentinel/slots/statistic/data/MetricBucket.java): PASS counter and reset.
- [ArrayMetric](https://github.com/alibaba/Sentinel/blob/a3f40ba8e900c8489bd520274739f17235a7721c/sentinel-core/src/main/java/com/alibaba/csp/sentinel/slots/statistic/metric/ArrayMetric.java): the statistics entry calls `currentWindow` before aggregating `values`. Its default constructor uses the occupiable implementation; this example explicitly simulates only BucketLeapArray.

The model is fixed at 4 slots, a 2000 ms interval and 500 ms buckets. Guided steps and free exploration show same-window reuse, new buckets across windows, no backfill when windows are skipped, and single-slot reset after a full rotation. Time changes are separate from access operations: read-only `values` filters valid buckets without modifying the array, and expired buckets remain in storage. The check is `time - start > interval`, so equality is still valid; this is not an exact sliding window storing every sample timestamp. The clock-rollback branch returns an independent new bucket without writing it back; `values` has no extra condition excluding future buckets. For negative time, `currentWindow` returns null and `values` returns an empty list.

This is a plain TypeScript teaching model. It does not run Java, verify lock/CAS contention or real performance, or cover the occupiable bucket extension. The page performs no external business operations and emits no browsing events. The human's experience and follow-up questions are for the main agent to confirm; do not report automated checks as the human having tried the page.
