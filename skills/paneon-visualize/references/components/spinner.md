# Spinner

## Use when

Show that something is loading or a request is in progress.

## Import

```ts
import { Spinner } from '@qoggy/paneon/ui';
```

## Props

```ts
// Spinner renders a spinning lucide <svg> with role="status" and a localized "Loading" label;
// other <svg> props are accepted.
interface SpinnerProps {
  className?: string; // default size-4
}
```
