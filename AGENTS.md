paneon is a CLI-first tool for building human–agent interfaces with TypeScript and React.

## Project Memory

Before work that depends on durable project conventions, read `docs/memory/MEMORY.md` and follow its relevant links; use `$paneon-memory` when reading or maintaining project memory.

## Common Commands

```bash
npm ci                       # Install dependencies
npm run dev                  # Start the React development server
npm run dev:cli -- --help     # Show CLI help
npm run build                # Type-check and build the CLI and web interface
npm test                     # Build the CLI and run automated tests
npm run lint                 # Run ESLint
npm run format               # Format files with Prettier
npm run format:check         # Check formatting
npm run typecheck            # Run TypeScript type checking
```
