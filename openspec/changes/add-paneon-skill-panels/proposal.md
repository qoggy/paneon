## Why

当前示例主要证明组件和调用桥可以工作，未提供常见人机交互可直接复用的入口。用户已选择通过 Paneon skill 分发标准页面和场景示例，让 agent 准备数据即可运行标准页面，需要自由布局或业务集成时再复用示例编写 TSX。

本 change 的页面范围与交互已对焦，工程契约核对见 design.md 的定稿章节及 review.md。标准页、公共反馈 API、Git/PR 内容定位、skill 打包及验收范围已明确；Sentinel 已在实施时核对固定公开源码。当前没有新增产品决策。标准页/示例、公共反馈、文件入参、只读 PR 和 CLI init 已实现；B43–B46 体验修正也已集成，最终验收证据见 verification.md。用户亲自体验 Sentinel 仍单独保留，不据工程验证宣称整个 change 已完成。

## What Changes

- 提供独立的产品 skill，标准页面和示例源码收在 skill 资源中；CLI 保持通用 TSX 运行入口。
- 不为标准页面增加首页目录或特殊启动区域；运行后的页面使用现有实例列表。
- 方案选择页支持只选选项、选项加说明、自填答案，以及在同一页面依次回答多个问题。
- 一轮问答最后统一提交全部答案；新一轮创建新面板实例，按实例关联该轮问题和结果。
- 保留方案标题、摘要、Markdown 详情、推荐标记和单选/多选能力；将问题内容放入 questions 数组，以稳定问题 ID 和选项 ID 关联反馈。
- 已确定标准页面包含方案选择、信息收集、交互式数据表和支持多仓库的本地 Git 变更审阅；表格传入数据即可使用。内容审阅按 B30 采用 title/markdown 输入，支持整篇、正文段落和词句精准批注并统一提交 annotations；各页工程契约见 design 定稿。
- 交互表格保持数据只读，支持表头/字符串单元格文字批注、整体批注、目录、定位与明确提交；默认对象选择和行列勾选已移除，既有对象 ref 校验保留。结果以原始 rows 的零基下标和 columnKey 定位，不要求 id 或 rowKey。
- GitHub PR 示例通过真实 gh 读取列表、说明、文件改动和检查状态；按 B31，仅向当前 AI 交付审阅请求及意见，不提供 GitHub 批注发布或其他写操作。
- 并发讲解现为哲学家就餐 example，已替代初版任务时长/并发数示例；主题和模型写在源码，用户在页面内探索资源获取策略，不接收业务 JSON 或发出批注事件。
- 所提供标准页允许在原页更正已提交结果，再明确提交完整修正版并保留历史；自定义页面仍可自行实现其他提交后策略，框架不强制套用。
- 提供可选的公共选择与批注 SDK/UI，标准页、示例和自定义 TSX 复用状态管理、对象/普通文本选择、批注编辑和明确提交；页面提供语义位置与内容版本，skill 提供接入指南。
- 新增通用 --params-file，创建实例时从 JSON 文件读取快照，与现有 --params 二选一，标准页面和自定义 TSX 均可使用；修改原参数文件不改变已有实例，源码 watch 语义保持原样。
- skill 随 CLI 包以同一版本发布；按 B38/B40 提供 paneon init 统一安装入口，Project/Global、共享目录复制与跨目录链接/复制选择，以及汇总覆盖确认。元数据按 B41 集中放 ~/.paneon。用户现已授权实现 init；B42 的 update 仅记录、不在本期实施。

- 提供以已核对的 Sentinel 固定公开源码为准的 LeapArray 展示；初始主题/场景在源码，用户可在页面内探索请求场景和参数，用户亲自体验仍待完成。

- 修正现有 HTTP 字节限制与事件字符限制的冲突，保留事件语义上限，提供准确的体积诊断。

## Capabilities

### New Capabilities

- `paneon-agent-skill`: 面向使用者的 skill、标准页面与示例资源归属，以及按需读取的使用说明。
- `guided-choice-panel`: 多问题方案选择、补充说明、自填答案和结构化交互结果。
- `panel-file-input`: 通用 CLI JSON 文件入参、互斥选项、路径解析和读取/校验行为。
- `panel-feedback`: 可组合的公共选择/批注 SDK/UI、业务对象与文字范围目标、页面适配和显式事件提交。

### Modified Capabilities

无。现有核心运行能力仍位于未归档 change，本 change 不重写其规范。

## Impact

涉及公共 SDK/UI 模块与导出、产品 skill 资源、打包清单、标准页面输入/事件契约和使用文档。复用现有 panel run、serverAction 和 agent events/ack；不引入按 agent 厂商绑定的协议。暂不新增数据库结构、首页目录或 builtin 名称解析。具体实施路径和需求门槛见 design.md、tasks.md。
