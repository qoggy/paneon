## 已发现并纳入实施的缺口

1. **HTTP 字节限制与事件字符限制冲突。** src/runtime/server.ts 的 bodyLimit 为 131072 字节；src/runtime/lifecycle.ts 的事件限制为 65536 个 JSON UTF-16 字符。中文长反馈可能尚未到达事件上限就被 HTTP 拒绝。设计已要求 262144 字节请求上限、保留事件上限、发送前检查和 HTTP 413 / BODY_TOO_LARGE；当前代码尚未修复。
2. **公共反馈 API 和文本定位尚不存在。** 当前 SDK 只有事件桥等基础，Markdown 渲染也没有源位置适配。已明确需要实现状态、原文注册及页面适配器，不能把引入组件误认为完成批注能力。
3. **PR head 不足以标识说明和检查版本。** 已分别保留描述摘要和检查所见状态；代码来源使用固定 OID，避免将实时 diff 附到另一次查询的版本上。GitHub 比较接口的文件范围限制依据 [官方文档](https://docs.github.com/en/rest/commits/commits?apiversion=2022-11-28#compare-two-commits) 记录，尚未作外部仓库端到端查询。
