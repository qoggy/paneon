## Goals / Non-Goals

目标：多个目录和显式文件能在同页阅读、批注和提交。

不做：忽略规则、名称过滤、目录选择器、文件监听、实时刷新、来源 origin 模型、快照证据正文优化、通用资源上限或框架重构。

## Decisions

### 输入和身份

`files?: string[]` 与 `directories?: string[]` 沿用原有非空白字面路径要求；两者合计至少一个路径。保留原有 title、未知字段及类型规则。路径相对 --cwd 或为绝对路径，不按 glob/URL 解释。

显式 files 是原序号前缀，保留显式重复项。随后按目录输入顺序追加扫描项；每个根的结果以路径字符串排序，与显式及此前扫描项重叠的规范绝对路径不再追加。页面加载完成后清单固定，搜索、导航和提交不重扫或重新编号。

### 枚举

新增 [directory.ts](../../../../skills/paneon-visualize/assets/panels/file-review/directory.ts)，使用 Node opendir 遍历元数据，不读取正文。普通目录递归；符号链接保留 readlink 的原始目标，并通过 stat 区分文件、目录和不可访问目标。文件链接与其他文件条目仍由既有 reader 决定预览资格；目录链接在初始化时递归收集目标内容，包括指向输入目录之外的目标。显式文件和目录根也识别符号链接。

本次没有按名称隐藏或排除目录的逻辑，也不引入规则配置。合并按规范绝对路径身份处理；相同路径在此前已用相同或更少的祖先约束扫描过时不重复遍历。显式输入一个先前从其他根扫描到的目录时，祖先链从该输入重新开始，不继承前一个输入的循环判断。realpath 仅用于比较当前目录链的实际目标，返回祖先目录的链接标记为循环，不递归；它不参与全局去重，不隐藏其他别名。同一实际目标经不同链接访问时，分别保留链接路径；批注、读取和公开反馈继续使用该路径。

ENOENT、ENOTDIR、EACCES、EPERM、EIO、ELOOP 作为可见目录读取问题返回，保留已发现条目与其他来源；未知异常上抛。空目录是正常结果，不读取不存在的首项。

链接目标不可访问时保留目标及错误信息，界面显示失效状态，打开时沿用已有 reader 的错误处理。显式文件元数据读取失败时记录日志，不阻断原有文件预览。循环判断仅终止自动递归，不拒绝显式文件路径，也不增加目录数、文件数、深度、扩展名或目标范围限制。

### 复用现有 actions 和页面

- resolvePaths 接收原输入，返回 files（显示路径）、paths（绝对路径）、directories（解析后的输入目录）、links（链接类型、原始目标、循环和错误信息）、issues。
- readFile 接收单个 path、fileIndex；沿用已有 reader，不增加索引范围限制。
- validateFeedback 保留显式文件路径核对；目录发现项按原输入目录的路径段归属核对，不重扫目录或核对正文。不新增 origin 等身份字段。
- files-only 页面保持原显示路径和展开行为；目录模式在输入目录处保留路径压缩边界，初始展开各输入目录及其祖先，并展开显式文件的祖先使其可见，其他内部子目录保持折叠。完整搜索和全部展开仍可用。
- 目录内条目在 cwd 内展示相对路径，cwd 外使用绝对路径；Markdown 资源继续按实际路径解释。
- 目录失败展示已有 Alert，空结果用 Empty，加载用 Spinner；没有忽略设置或排除数量 UI。文件列表加载、空目录和列表读取失败均位于左侧导航，Tree 的 loading 与发现请求状态绑定；加载期间不显示无匹配结果。右侧尚无文件时保持空白，已传入的显式文件仍可预览。
- 树模型保留目录链接节点，包括空目录和循环引用，并在链接处保留压缩边界。目录链接使用文件夹图标，文件链接使用文件图标，均叠加箭头；失效链接显示错误状态。Tree 组件不改动，循环节点不作为文件选择。tooltip 锚定图标与名称，内容仅为链接目标，循环时追加“（循环）”，不增加行内标签。预览顶部用单行显示链接路径和目标，保持原工具栏高度。
- 本次保持既有 evidence 和公开批注事件，传输上限不变；不顺带实施之前讨论的正文证据优化。
