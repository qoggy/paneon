## 本轮推荐界面

### 管理顶栏

品牌 Paneon 靠左，其右侧是同一层级的「面板 / Panels」「服务 / Server」「设置 / Settings」。默认进入面板页。使用紧凑文字导航和低强调的当前项指示，不把导航做成三个大按钮，不设置居中的 Settings 按钮，也不再另外增加齿轮入口。

三个页面共享顶栏和内容容器。只有三项时使用顶部导航，不为假设中的更多命令提前增加固定侧边栏、空分类或多级菜单。窄屏可将品牌与导航分为两行，所有入口保持可见、可键盘操作，不强行塞入一行。

一级导航属于 Paneon 管理界面，不进入 `/panels/:instanceId` 的内容页面。具体 panel 继续保持无永久顶栏、无外加导航的现有边界。

### 面板页

- `panel` 对应的管理空间：实例列表、状态、打开和关闭；保留当前卡片及分页，本轮不重做列表。
- 内容标题「面板 / Panels」右侧保留局部 Refresh；刷新只作用于当前列表。
- 具体面板链接仍进入原 `/panels/:instanceId`，不嵌套管理导航。

### 服务页

- `server` 对应「本地 Paneon 服务」的状态页，展示已有真实字段：运行状态、版本、PID、监听地址和启动时间；用普通属性列表呈现。
- 不画缺乏采集依据的 CPU/内存图，不把服务页设计成虚构监控大屏，也不混入其他业务服务。
- 本轮设计以只读状态为边界，不添加停止/重启服务按钮；若用户另行要求网页控制停服，需要单独对焦控制权限及停服后网页失联的反馈。
- 服务离线时，这个由服务自身提供的网页也不可访问，不能宣称它能管理一个已经停止的服务。CLI 仍是离线状态检查和停止操作的权威入口。
- 此前讨论的闲置回收、运行资源策略在概念上属于服务管理，但它们尚未设计或实现，不为本次导航加入相应控件或占位项。

### 设置页

`config` 对应面向人的「设置 / Settings」，无需把 CLI 单词直接显示成 Config。点击一级设置导航进入 `/settings`，普通页面展示偏好，无 Dialog、遮罩或侧滑浮层。

- 内容标题为普通字号的「设置」，不添加「设置 Paneon 的显示偏好」等重复副标题；无需额外返回按钮，点击一级「面板」即可返回。
- 正文约 640px 上限，左对齐于应用内容区，不拉满整个屏幕，不把两项设置分成大卡片。
- 外观一行：左侧「外观」，右侧紧凑「浅色 / 深色」选项，不添加解释性小字。
- 语言一行：左侧「语言」，右侧「English / 简体中文」选择控件，不重复解释语言设置的作用。
- 设置按行排列，用细分隔线组织，无重复大标题、无孤立主要提交按钮。
- 窄屏标签和控件上下排列，不依赖悬停说明。

## 导航组织原则

- CLI 与网页共享对象边界，不机械共享每一项命令。
- 持续管理的对象且有明确内容时，才适合作为一级导航。`panel`、`server`、`config` 可以对应三个空间。
- 一次性动作留在对应流程。例如 init 不因存在于 CLI 就自动成为一级菜单；reload/close 是面板操作，不是新导航。
- 将来新增 subcommand 时，先判断它是现有空间内的动作，还是新的管理对象；只有后者且有实际网页内容时才增加导航。不在本轮添加未来菜单。

## 交互

- 延续现有即时保存。主题、语言点选后通过当前保存链路生效，所有已连接页面收到同一偏好。
- 保存中防止重复写入，成功后用低强调文字/状态图标反馈「已保存」，不用 Toast 或确认弹窗。
- 保存失败在对应设置区域展示错误，控件准确反映最后确认的值，保留再次操作能力。不得显示虚假成功状态。
- 不新增 Save/Cancel 按钮、自动跟随系统主题或其他偏好项。
- 切回面板恢复列表页码和滚动位置，不因为切换导航而重新创建或关闭 panel。
- 面板首页保持 `/`，服务页建议 `/server`，设置页为 `/settings`；支持直接访问、刷新和浏览器前进/后退。沿用 React 架构，不为本次改造添加路由依赖。

## 接口与数据

设置沿用 `GET /api/preferences`、`POST /api/preferences` 与 `GET /api/preferences/stream`；服务状态复用 `GET /health`。本设计不修改控制接口或存储结构。偏好仍由用户级 `~/.paneon/config.json` 保存，例如：

```json
{
  "ui": {
    "theme": "dark",
    "language": "zh-CN"
  }
}
```

语言值仍为 `en` / `zh-CN`，主题值仍为 `light` / `dark`。只修改当前设置字段，不覆盖其他配置内容；不自动翻译 Agent 提供的内容。
