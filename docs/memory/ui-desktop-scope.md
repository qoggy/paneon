# Desktop page scope

Develop and accept pages for desktop use by default. Dedicated mobile layouts, touch-specific adaptations, mobile screenshots, and mobile test matrices are outside the default task scope; do them only when explicitly requested by the user or required by the task. Existing responsive component behavior can remain without additional mobile-specific work.

**Why:** Unrequested mobile work adds development time and token cost without serving the agreed desktop scope.
**How to apply:** Apply this scope to implementation, delegated tasks, and acceptance criteria. Do not add mobile testing as a routine completion requirement.
