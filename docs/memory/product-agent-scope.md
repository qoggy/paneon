# Agent scope

Paneon provides human–agent interfaces for general-purpose agents. Product descriptions refer to agents without restricting the product to a particular task category.

An agent can run an existing panel and read or acknowledge interaction events through the local CLI. Creating a new panel also requires generating TypeScript and React source. These are tool and environment capabilities, rather than a requirement for a particular agent product.

**Why:** The interface runtime is useful across different agent tasks.
**How to apply:** Use agent in product descriptions and keep examples generic unless they intentionally demonstrate a specific use case.
