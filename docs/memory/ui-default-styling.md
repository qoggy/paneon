# Default UI styling

Public components follow shadcn's default themes and component styles, without a separate Paneon visual system. Layout components provide necessary layout only; panel authors may customize their pages.

**Why:** Reuse established component styling instead of maintaining another global visual specification.
**How to apply:** Use upstream defaults for public components and keep page-specific customization in panel code.
